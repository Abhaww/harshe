🚀 Shigar da Harshe a Kwamfutarka (Download & Install)

1. Windows (PowerShell One-Line Command)

irm https://raw.githubusercontent.com/harshe-lang/harshe/main/install.ps1 | iex

2. Linux & macOS (Terminal One-Line Command)

curl -sSL https://raw.githubusercontent.com/harshe-lang/harshe/main/install.sh | bash

3. Ta Hanyar Python (Pip)

pip install harshe

4. Saukar da Fayil din .exe Kai-tsaye (Direct Executable)

Sauke harshe.exe domin gudanar da Harshe a Windows ba tare da bukatar kowanne abu ba.
