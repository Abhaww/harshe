# Harshe (HausaLang) 🚀
**Harshen Shirye-shiryen Kwamfuta na Farko a Yaren Hausa**  
*The First Native Hausa Programming Language & Ecosystem*

---

## 📖 Gabatarwa (Overview)

**Harshe (HausaLang)** harshe ne na shirye-shiryen kwamfuta (programming language) wanda aka gina shi tun daga tushe domin ba wa al'ummar Hausawa da masu koyon fannin fasaha damar rubuta lambobin kwamfuta (coding) cikin yarensu na gida.

---

## 🌟 Sabbin Abubuwa (Features & Ecosystem)

1. **Nahawun Hausa Zalla**: Kalmomi kamar `bari`, `tsayayye`, `idan`, `ko idan`, `in ba haka ba`, `yayin da`, `ga ... a cikin`, `aiki`, `koma`, `gwada`, `kama`.
2. **Tsarin Shigo da Laburare (`shigo_da`)**: Rarraba manyan ayyuka da laburaren lissafi, rubutu, da lokaci.
3. **Standalone `.exe` Compiler**: Hada kowane shirin Harshe zuwa fayil din `.exe` wanda yake aiki a kowace kwamfuta ba tare da an shigar da Python ba.
4. **Kunshin Laburare (`kunshi`)**: Tsarin shigar da laburaren al'umma (`python harshe_cli.py shigar <kunshi>`).
5. **Interactive Web IDE & Academy**: Dandalin koyon coding a yanar gizo mai darussa 8 da allon zane (Canvas Graphics).
6. **VS Code Extension**: Haskaka nahawu (syntax highlighting) da gajerun hanyoyi (snippets) a Visual Studio Code.

## 🚀 Yadda Ake Amfani (Quick Start)

### 1. Gudanar da Shirin Harshe (Run Code)
```bash
python harshe_cli.py run examples/01_sannu_duniya.hausa
```

### 2. Hada Shirin zuwa `.exe` (Compile to Standalone Windows Binary)
```bash
python harshe_cli.py compile examples/01_sannu_duniya.hausa -o sannu_app
# Zai fitar da: dist/sannu_app.exe
```

### 3. Fara Sabon Aiki (Scaffold New Project)
```bash
python harshe_cli.py sabo sabon_aikina
python harshe_cli.py run sabon_aikina/babban_shiri.hausa
```

### 4. Bude Dandalin Yanar Gizo (Interactive Web IDE & Academy)
```bash
start web/index.html
```
