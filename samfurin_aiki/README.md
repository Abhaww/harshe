# samfurin_aiki

Wannan aiki ne da aka kirkira ta amfani da **Harshe (HausaLang)**.

## Gudanar da Shirin (Running the Project)
```bash
python harshe_cli.py run samfurin_aiki/babban_shiri.hausa
```

## Gudanar da Gwaje-gwaje (Running Tests)
```bash
python harshe_cli.py run samfurin_aiki/gwaje_gwaje/gwada_aiki.hausa
```
